# Termix 应用图标设计说明

版本：v2.0（重设计）｜日期：2026-08-14

---

## 1. 设计理念

Termix 是一款 SSH 终端管理工具，核心场景是"连接远程服务器、在终端中执行命令"。图标设计围绕三个关键词展开：

- **终端（Terminal）**：以经典命令提示符 `>` 作为视觉主体，一眼可识别为 CLI 工具；
- **连接（Connection）**：`>` 后紧随闪烁光标 `_`，隐喻"正在等待输入、会话已建立"；
- **专业（Professional）**：深色金属质感工作台面 + 克制的玻璃高光，传达稳定、可靠的工具属性。

整体采用**极简几何符号 + 质感背景**的组合策略：远看是"一块深色圆角面板中的绿色指令符"，近看细节丰富但不冗余，保证品牌识别度与专业度并重。

## 2. 色彩选择

| 色彩 | 色值 | 用途与含义 |
|------|------|-----------|
| 品牌绿 | `#32F08C` | 终端提示符与光标。与产品 UI 主题色（`--bg-brand`）完全一致，强化品牌一致性；绿色同时象征"在线、连接成功、生命力" |
| 深色面板 | `#2E3137 → #0F1013`（对角渐变） | 图标基底。左上亮、右下暗的金属质感，模拟终端工作台的深邃感 |
| 玻璃高光 | 白色 10% → 0%（顶部渐变） | 顶部弧面高光，Modern Big Sur 质感，提升精致度 |
| 边缘描边 | 白色 7% 细线 | 勾勒轮廓，避免深色背景在浅色壁纸上融为一体 |

**对比度**：品牌绿在深色面板上的对比度约 8.9:1，远高于 WCAG AA 的 4.5:1，确保小尺寸下符号依旧清晰可辨。

## 3. 元素含义

```
┌─────────────────────────┐
│ ▓▓▓▓▓ 玻璃高光          │   ← 质感与层次
│                         │
│        >_               │   ← 提示符 + 光标
│                         │
│  ░░░░░░░░░░░ 底部微反光 │   ← 立体感
└─────────────────────────┘
```

- **圆角方框（rounded rect）**：应用图标的标准容器形态，圆角约 24%，接近 macOS「squircle」，三平台通用；
- **`>` 提示符**：Unix/Linux Shell 的经典 prompt 符号，直接点明"命令行/SSH 会话"功能；
- **`_` 光标**：下划线光标代表"输入就绪 / 活跃会话"，与 `>` 组成 `>_`，传达"随时开始输入"的交互暗示；
- **辉光（glow）**：符号外层 26px 高斯模糊的绿色光晕，让符号在深色面板上"发光"，视觉聚焦；
- **玻璃高光 / 底部反光**：呼应现代 macOS/iOS 图标语言，也兼容 Windows 11 的亚克力质感审美。

## 4. 多尺寸适配策略

图标以 **1024×1024 单一矢量源** 缩放生成，核心符号控制在画布中央约 46% 面积内，保证各尺寸的视觉一致性：

| 尺寸 | 用途 | 表现 |
|------|------|------|
| 16×16 | Windows 任务栏（小图标）、浏览器标签 | 圆角抗锯齿收敛，四角微透明；中央绿色符号仍清晰可辨 |
| 32×32 | Windows 桌面、macOS 菜单栏、Dock | 符号轮廓完整 |
| 48×48 | Windows 桌面大图标 | 细节完整 |
| 128×128 | macOS Finder/工具栏 | 高光与辉光可见 |
| 256×256 | Windows 设置、商店图标 | 完整质感 |
| 512 / 1024 | macOS Dock、应用商店、分发用源 | 全细节呈现 |

> 提示：16px 是极限压缩场景，任何渐变/发光细节都无法保留；本设计在 16px 下退化为"深色圆角块 + 中央绿点"，依旧保持可辨识。

## 5. 各平台规范适配

### macOS
- 提供 `.icns`（含 16/32/64/128/256/512/1024 全分辨率）；
- 圆角方框内留白极少，符合 macOS 图标"满幅图形 + 系统自动裁切 squircle"规范；
- 深色主体在浅色/深色 Dock 上均有足够对比。

### Windows
- 提供 `.ico`（内嵌 16/24/32/48/64/128/256 六档尺寸，PNG 压缩格式）；
- 四角透明，Windows 10 任务栏显示方形、Windows 11 自动圆角，均无违和；
- 同步提供 Store 系列规格（`Square30~310`、`StoreLogo` 等）。

### Linux
- 提供 16/32/48/64/128/256/512/1024 各尺寸 PNG，适配 GNOME/KDE 等桌面环境的图标规格。

### iOS / Android（Tauri 移动端支持）
- 由 `tauri icon` 自动生成 `AppIcon-20~83.5` 全套及 `mipmap-*` 全套。

## 7. 重新生成方法

如需调整配色或形状后重新生成全套平台图标：

```bash
# 1. 编辑矢量源
open design/brand/termix-icon.svg

# 2. 渲染 1024 PNG（需 node + sharp，已作为 devDependency 安装）
node -e "require('sharp')('design/brand/termix-icon.svg',{density:300}).resize(1024,1024).png().toFile('design/brand/termix-icon-1024.png')"

# 3. 重新生成全套平台图标（覆盖 src-tauri/icons/）
npx tauri icon design/brand/termix-icon-1024.png
```

> 说明：原始设计稿以 SVG 矢量格式交付（可无损导入 AI/PSD，无损放大缩小）；如确需 PSD 位图层级文件，可在 Illustrator 中"文件 → 导出 → 保存为 Photoshop 格式"生成。
