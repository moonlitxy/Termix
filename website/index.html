常见问题

会收集我的数据吗？

不会。Termix 没有遥测与账号体系，连接信息、密码和备份都只保存在本机。

支持 2FA 和跳板机吗？

支持。键盘交互认证会在连接时提示输入验证码；跳板机可选任意已保存会话（仅一级）。

能导入原有 SSH 配置吗？

可以。一键读取 ~/.ssh/config，或选择配置文件导入，自动识别 Host / HostName / User / Port / IdentityFile。

更新失败怎么办？

在「设置 → 软件更新」切换镜像或配置代理，点「测试连接」确认可用后再更新。
