---

## 一、项目概览

Termix 是一款面向开发者与运维人员的跨平台 SSH 终端连接工具（对标 MobaXterm / FinalShell），集成连接管理、多标签终端、SFTP、端口转发、系统监控等能力。当前以 macOS 为开发主环境，产物可打包 Windows/macOS 安装包。

### 技术方案
| 层 | 选型 | 说明 |
|---|---|---|
| 桌面框架 | Tauri 2 | 复用系统 WebView，安装包 5-15MB，内存约为 Electron 1/3 |
| 后端 | Rust + russh / russh-sftp | SSH/SFTP 协议、async（tokio） |
| 前端 | React 18 + TS + Vite | xterm.js 终端、zustand 状态管理、SVG 图标 |
| 存储 | SQLite（rusqlite bundled） | 会话 / 分组 / 命令历史 / 片段 / 转发规则 |
| 日志 | env_logger | 默认 info 级，`RUST_LOG=debug` 更详细 |

## 三、已完成功能明细

### 3.1 MVP — 连接管理与终端（100%）
- **连接管理**：新建 / 编辑 / 删除 / 复制连接信息；密码与私钥认证；分组管理
- **会话侧边栏**：最近连接列表、分组、在线/离线状态圆点与标签；双击打开终端
- **会话右键菜单**：在新标签连接 / 编辑 / 复制连接信息 / 删除
- **多标签终端**：xterm.js 渲染、多标签切换、标签右键菜单（关闭 / 关闭其他 / 关闭右侧 / 复制标签 / 重命名标签）、断开连接
- **命令输入区**：输入命令 + 执行按钮 + 历史下拉（按会话持久化、上下键切换）
- **工具栏**：复制选中、保存日志（下载 .log）、清屏、断开
- **全局快捷键**：`⌘/Ctrl+T` 新建连接、`⌘/Ctrl+D` 断开当前、`Ctrl+/-` 终端字号缩放
- **标题栏搜索框**：按名称/主机/用户名过滤会话列表

### 3.2 v0.2 — SFTP 与传输队列（100%）
- **SFTP 双栏**：本地/远程文件浏览、双击进目录、路径栏可编辑跳转、上级目录
- **文件操作**：上传、下载、新建文件夹、删除、重命名（远程）
- **拖拽传输**：
  - 系统文件拖到远程栏 = 上传（Tauri `onDragDropEvent` 获取绝对路径，支持批量）
  - 本地行拖到远程栏 = 上传；远程行拖到本地栏 = 下载
  - 拖拽悬停目标栏高亮
- **断点续传**：上传/下载按文件偏移续传（远端/本地已完整则跳过，远端比本地大则从头覆盖），失败重试自动从断点继续
- **暂停/恢复**：传输中可暂停（保留半成品文件），恢复后自动断点续传；暂停后可取消
- **传输队列（右侧面板）**：实时进度条、速率、暂停/恢复、取消 / 失败重试；完成/失败/取消任务保留 5 秒后自动移出
- **上传/下载完成自动刷新**对应目录

### 3.3 v0.3 — 端口转发、命令片段、系统监控（100%）
- **端口转发**：
  - 本地转发：规则 CRUD、启停、编辑、端口占用检测；隧道双向拷贝
  - 远程转发：请求服务端监听端口（`tcpip-forward`），连接经 `forwarded-tcpip` 通道推送后转发到本地目标
  - 动态 SOCKS5 代理：本地监听端口作为 SOCKS5 代理，支持 IPv4/域名/IPv6 目标，无认证握手
- **命令片段**：片段 CRUD（标题/命令/分组）、一键插入当前终端、变量占位符 `{{var}}` 交互填充弹窗（支持 variables 字段默认值）
- **系统监控**：
  - 右侧面板常驻：CPU / 内存 / 磁盘 / 网络速率 / 网络连接数，刷新间隔可在设置中调整（1/2/5 秒）
  - 监控页：指标卡 + CPU 实时曲线（SVG，最近 60 点）+ 磁盘分区详情（挂载点/容量/使用率）+ 进程 Top 列表

### 3.4 v0.4 — 设置（~85%）
- **设置页**：深色/浅色/跟随系统主题、界面字号、光标样式、滚动缓冲区、监控刷新间隔；localStorage 持久化
- **安全设置**：主密码（PBKDF2 派生密钥 + AES-256-GCM）加密会话密码/私钥密码；设置/修改/解锁/锁定/清除；解锁后连接自动解密，锁定时新建会话需先解锁
- **快捷键说明**：展示页

### 3.5 增强与健壮性
- **日志体系**：SFTP 传输 / 端口转发全链路日志（会话建立、文件操作、任务进度、隧道连接、错误原因）
- **传输取消真正生效**：`AtomicBool` 取消标志，取消时清理远程/本地半成品文件
- **自动重连**：网络意外断开后自动重连最多 3 次（间隔 2s），成功恢复会话；手动断开不触发
- **边界情况处理**：网络断开（任务标记失败、自动重连）、文件被占用、路径不存在、空文件、端口占用等均有明确反馈（详见代码）

### 3.6 体验优化（竞品对标第一梯队）
- **终端右键菜单**：终端内右键弹出菜单（复制 / 粘贴 / 清屏），复制写入系统剪贴板；粘贴剪贴板内容，若含多行文本先弹确认框再发送，避免误粘贴
- **SSH 心跳保活**：连接层配置 `keepalive_interval=30s` + `keepalive_max=3`，空闲时发送 keepalive 维持 NAT/防火墙会话，连续 3 次无响应判定断线（触发自动重连）
- **快捷命令面板**：工具栏"快捷命令"按钮弹出命令面板，复用命令片段数据，支持关键字搜索、一键发送到当前终端；含 `{{var}}` 占位符的片段先弹出变量填写表单

### 3.7 会话导入 / 导出（竞品对标第二梯队）
- **导出**：会话侧边栏导出按钮，将全部会话 + 分组导出为 JSON 备份文件（`termix-sessions-YYYYMMDD.json`）；主密码已解锁时密码解密为明文导出，便于跨设备迁移
- **导入**：选择备份文件导入，分组按名称去重复用、会话按名称去重跳过；导入的密码遵循既有加密策略（明文加密存储、密文原样保留）；完成后自动刷新会话与分组列表

### 3.8 分屏 与 SFTP 右键菜单（竞品对标第二梯队）
- **分屏**：编辑器工具栏分屏按钮，基于当前活动会话新开一个独立终端 pane（横向并排，最多 4 屏）；pane 不占用标签栏、右上角可单独关闭、随主标签级联关闭；每个 pane 独立连接/自动重连/右键菜单
- **SFTP 右键菜单**：远程/本地文件列表支持右键菜单——远程：下载/下载目录、重命名、删除、复制路径；本地：上传/上传目录、复制路径；空白处右键：新建文件夹（远程）、刷新

### 3.9 单元测试（Rust 30 个 + 前端 14 个，全部通过）
- **`crypto.rs`（主密码加密）**：PBKDF2 派生密钥、AES-256-GCM 加解密回环、错误密钥解密失败、密文格式校验、主密码校验：5 个
- **`commands.rs`（监控解析纯函数）**：`parse_first_f64` / `parse_mem` / `parse_disks`（多分区、含空格挂载点）/ `parse_conns` / `parse_net`，覆盖正常、空串、非法输入
- **`sftp.rs`（路径与列表工具）**：`sort_items` 目录优先排序、`join_remote` 根目录拼接、`local_list` 临时目录真实扫描、`collect_local_files` 递归收集
- **`db.rs`（SQLite CRUD）**：用 `:memory:` 内存库覆盖会话/分组/历史/片段/转发规则的增删改查与级联删除、转发启停
- **`models.rs`（会话备份结构）**：备份 JSON 序列化/反序列化回环、外部文件 app 标识校验：2 个
- **前端（vitest）**：`split.test.ts` 覆盖分屏上限判定、pane 标题、store 分屏行为（addTab 不改变激活、closeTab 级联关闭 pane）；`sftpMenu.test.ts` 覆盖远程/本地/空白区右键菜单项组合：14 个
- 运行方式：后端 `cd src-tauri && cargo test`；前端 `npm test`（SSH/SFTP 网络类功能依赖真实连接，未做集成测试）

## 五、项目结构

```
Termix/
├── design/                  # PRD 与设计原型（index-v2.html、图标资源）
├── docs/                    # 开发文档（本文件）
├── src/                     # 前端（React + TS）
│   ├── components/          # 布局与功能组件（TitleBar/ActivityRail/终端/SFTP/转发/监控/设置等）
│   ├── store/app.ts         # zustand 全局状态
│   ├── lib/                 # IPC 封装、终端注册表
│   ├── styles/              # 设计 token + 全局样式（深/浅主题）
│   └── assets/icons/        # 设计稿 SVG 图标（复用 design/assets/icons）
└── src-tauri/               # 后端（Rust）
    ├── src/
    │   ├── main.rs          # 入口、命令注册、日志初始化
    │   ├── commands.rs      # Tauri IPC 命令
    │   ├── crypto.rs        # 主密码加密（PBKDF2 + AES-256-GCM）
    │   ├── ssh.rs           # SSH 连接 / 终端 channel / exec
    │   ├── sftp.rs          # SFTP 操作 + 传输任务队列
    │   ├── forward.rs       # 端口转发（本地 / 动态 SOCKS5）
    │   ├── db.rs            # SQLite（会话/分组/历史/片段/转发/设置）
    │   └── models.rs        # 数据模型
    └── Cargo.toml
```
