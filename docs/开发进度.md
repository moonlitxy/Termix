## 一、项目概览

Termix 是一款面向开发者与运维人员的跨平台 SSH 终端连接工具（对标 MobaXterm / FinalShell），集成连接管理、多标签终端、SFTP、端口转发、系统监控等能力。当前以 macOS 为开发主环境，产物可打包 Windows/macOS 安装包。

### 技术方案
| 层 | 选型 | 说明 |
|---|---|---|
| 桌面框架 | Tauri 2 | 复用系统 WebView，安装包 5-15MB，内存约为 Electron 1/3 |
| 后端 | Rust + russh / russh-sftp | SSH/SFTP 协议、async（tokio） |
| 前端 | React 18 + TS + Vite | xterm.js 终端、zustand 状态管理、SVG 图标 |
| 存储 | SQLite（rusqlite bundled） | 会话 / 分组 / 命令历史 / 片段 / 转发规则 |
| 日志 | env_logger | 默认 info 级，`RUST_LOG=debug` 更详细 |

## 三、已完成功能明细

### 3.1 MVP — 连接管理与终端（100%）
- **连接管理**：新建 / 编辑 / 删除 / 复制连接信息；密码与私钥认证；分组管理
- **会话侧边栏**：最近连接列表、分组、在线/离线状态圆点与标签；双击打开终端
- **会话右键菜单**：在新标签连接 / 编辑 / 复制连接信息 / 删除
- **多标签终端**：xterm.js 渲染、多标签切换、标签右键菜单（关闭 / 关闭其他 / 关闭右侧）、断开连接
- **命令输入区**：输入命令 + 执行按钮 + 历史下拉（按会话持久化、上下键切换）
- **工具栏**：复制选中、保存日志（下载 .log）、清屏、断开
- **全局快捷键**：`⌘/Ctrl+T` 新建连接、`⌘/Ctrl+D` 断开当前、`Ctrl+/-` 终端字号缩放
- **标题栏搜索框**：按名称/主机/用户名过滤会话列表

### 3.2 v0.2 — SFTP 与传输队列（~95%）
- **SFTP 双栏**：本地/远程文件浏览、双击进目录、路径栏可编辑跳转、上级目录
- **文件操作**：上传、下载、新建文件夹、删除、重命名（远程）
- **拖拽传输**：
  - 系统文件拖到远程栏 = 上传（Tauri `onDragDropEvent` 获取绝对路径，支持批量）
  - 本地行拖到远程栏 = 上传；远程行拖到本地栏 = 下载
  - 拖拽悬停目标栏高亮
- **传输队列（右侧面板）**：实时进度条、速率、取消 / 失败重试；完成/失败/取消任务保留 5 秒后自动移出
- **上传/下载完成自动刷新**对应目录

### 3.3 v0.3 — 端口转发、命令片段、系统监控（~85%）
- **端口转发**（本地转发）：规则 CRUD、启停、端口占用检测；隧道双向拷贝
- **命令片段**：片段 CRUD（标题/命令/分组）、一键插入当前终端
- **系统监控**：
  - 右侧面板常驻：CPU / 内存 / 磁盘 / 网络速率，2s 轮询
  - 监控页：指标卡 + CPU 实时曲线（SVG，最近 60 点）+ 进程 Top 列表

### 3.4 v0.4 — 设置（~75%）
- **设置页**：深色/浅色主题、界面字号、光标样式、滚动缓冲区；localStorage 持久化
- **快捷键说明**：展示页

### 3.5 增强与健壮性
- **日志体系**：SFTP 传输 / 端口转发全链路日志（会话建立、文件操作、任务进度、隧道连接、错误原因）
- **传输取消真正生效**：`AtomicBool` 取消标志，取消时清理远程/本地半成品文件
- **边界情况处理**：网络断开（任务标记失败、终端变未连接）、文件被占用、路径不存在、空文件、端口占用等均有明确反馈（详见代码）

## 五、项目结构

```
Termix/
├── design/                  # PRD 与设计原型（index-v2.html、图标资源）
├── docs/                    # 开发文档（本文件）
├── src/                     # 前端（React + TS）
│   ├── components/          # 布局与功能组件（TitleBar/ActivityRail/终端/SFTP/转发/监控/设置等）
│   ├── store/app.ts         # zustand 全局状态
│   ├── lib/                 # IPC 封装、终端注册表
│   ├── styles/              # 设计 token + 全局样式（深/浅主题）
│   └── assets/icons/        # 设计稿 SVG 图标（复用 design/assets/icons）
└── src-tauri/               # 后端（Rust）
    ├── src/
    │   ├── main.rs          # 入口、命令注册、日志初始化
    │   ├── commands.rs      # Tauri IPC 命令
    │   ├── ssh.rs           # SSH 连接 / 终端 channel / exec
    │   ├── sftp.rs          # SFTP 操作 + 传输任务队列
    │   ├── forward.rs       # 本地端口转发
    │   ├── db.rs            # SQLite（会话/分组/历史/片段/转发）
    │   └── models.rs        # 数据模型
    └── Cargo.toml
```
