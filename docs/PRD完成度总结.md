## 三、异常与边界情况对照（PRD §7）

| 场景 | 状态 | 实现说明 |
|---|---|---|
| 连接超时 / 认证失败 | ✅ | 标签页/弹窗提示错误，可重试与编辑 |
| 私钥损坏/不存在 | ✅ | 连接失败给出明确错误信息 |
| 网络断开 | ✅ | 任务标记失败、终端显示断线提示；自动重连最多 3 次（手动断开不触发） |
| 命令执行超时 | ◑ | 终端内 Ctrl+C 可用，无独立超时按钮 |
| SFTP 权限不足 / 路径不存在 | ✅ | 错误信息明确提示 |
| 传输中断 | ✅ | 暂停/取消/失败可恢复与重试，自动断点续传 |
| 端口占用 | ✅ | 启动时检测并提示 |
| 拖拽上传失败 | ✅ | 逐文件汇总错误弹窗提示 |
