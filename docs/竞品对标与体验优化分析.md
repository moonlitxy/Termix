# Termix 竞品对标与体验优化分析

> 生成时间：2026-08-11
> 对标对象：MobaXterm / FinalShell / Xshell / Tabby / Termius
> 目的：梳理当前产品与竞品的体验差距，输出优先级明确的优化清单

---

## 一、最痛的体验缺口（高频使用场景）

| 痛点 | 现状 | 竞品情况 | 影响 |
|---|---|---|---|
| **终端右键菜单缺失** | 终端内右键无反应，复制需 Ctrl+Shift+C 或工具栏 | 全部竞品标配右键复制/粘贴 | 高频操作，用户感知强 |
| **无 SSH 心跳保活** | 仅 `inactivity_timeout=30s`，无主动 keepalive | 竞品默认开启心跳且可配置 | 挂机/长任务易被 NAT 掐断，被迫重连 |
| **无快捷命令面板** | 命令片段需手动打开片段页点击 | Xshell「快速命令按钮」、MobaXterm 宏 | 运维高频场景效率差 |
| **无终端内粘贴确认** | 直接粘贴多行 | 竞品有多行粘贴二次确认，防误执行 | 误操作风险 |

## 二、功能完备性差距（中等优先级）

| 差距 | 说明 |
|---|---|
| **分屏** | 工具栏有占位按钮未实现；Tabby / MobaXterm 标配 |
| **会话导入/导出** | 无；迁移/分享会话成本高（Xshell 标配） |
| **多窗口** | PRD 承诺「多窗口免费」，当前单窗口 |
| **连接选项缺失** | 超时/心跳/代理跳板机不可配（数据模型未含） |
| **监控历史** | 曲线仅内存 60 点，不持久化；竞品有历史/导出 |

## 三、体验细节优化点（低成本高感知）

1. **终端体验**：拖拽文本进终端、双击选词、多行粘贴确认、按会话记住光标/滚动位置
2. **SFTP**：右键菜单补全（下载/删除/重命名/权限/复制路径，当前为按钮式）；目录大小显示；双栏同步滚动
3. **会话侧边栏**：右键补「移动到分组」（当前缺失）；拖拽分组/会话；在线状态自动刷新
4. **设置**：启动时恢复上次会话、「记住最后连接」、字号/字体更细粒度
5. **反馈细节**：连接失败提供「重试」按钮直达（PRD 6.1 要求）；传输队列剩余时间估算（当前无）
6. **视觉**：浅色主题下部分组件未适配的边角；终端配色方案可自定义

## 四、优先级建议

### 第一梯队（高频、改动小，强烈建议）✅ 已完成
1. **终端右键菜单**：复制 / 粘贴 / 清屏 + 多行粘贴确认
2. **keepalive 心跳**：russh 原生支持（`keepalive_interval` / `keepalive_max`），改动很小
3. **快捷命令面板**：复用现有 snippet 数据，加一个工具栏弹层

> 实现记录（2026-08-11）：三项均已落地——
> 1. `TerminalView.tsx` 新增右键菜单（复制选中/粘贴/清屏），多行粘贴先弹确认框；
> 2. `ssh.rs` `client::Config` 配置 `keepalive_interval=30s`、`keepalive_max=3`；
> 3. `Toolbar.tsx` 新增"快捷命令"按钮，弹层支持搜索 + 一键发送 + `{{var}}` 变量填写。

### 第二梯队（价值高、工作量中）
4. **会话导入/导出** ✅ 已完成：JSON 备份（会话 + 分组），侧边栏导入/导出按钮；分组同名复用、会话同名跳过，密码遵循主密码加密策略
5. **分屏** ✅ 已完成：工具栏分屏按钮，同会话新开独立终端 pane（最多 4 屏），可单独关闭、随主标签级联关闭
6. **SFTP 右键菜单补全** ✅ 已完成：远程（下载/重命名/删除/复制路径）+ 本地（上传/复制路径）+ 空白区（新建文件夹/刷新）

### 第三梯队（远期）
- 多窗口
- 插件市场
- 云同步 / 用户系统
- 监控历史持久化与导出

## 附：本次分析的代码核对记录

- `ssh.rs` 仅配置 `inactivity_timeout=30s`，无 keepalive 心跳（`send_keepalive`/`ping` 未调用）
- 终端组件未实现 `onContextMenu` 右键菜单
- 分屏按钮为占位（无 onClick 行为）
- 会话右键菜单缺「移动到分组」「属性」
- 传输队列无「剩余时间」估算
